# HasStrip

Removes costly :has() stylesheet rules, with visual tradeoffs.

Copy the source files in this folder to `src/testcordplugins/HasStrip` in a compatible TestCord checkout, then build the client. Preserve the original author metadata and license headers. This copy is published as part of the maintained collection. See the root README for installation and validation limits.
